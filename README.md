# Игра: поиск секретика

Рабочая локальная версия, оформление без верхних надписей «ЛогоЛенд» и «Секретики». Восемь цветов, семь новых стеклянных спрайтов, поле 6 × 6, скрытое закапывание, плавное движение кисточки, раскопка маской за 2,85 секунды, сохраняющиеся пустые ямки, увеличение находки и новая игра.

## Запуск

Для исходников: `python3 -m http.server 8080` из этой папки. Открыть http://localhost:8080. Все игровые ресурсы находятся в папке assets и загружаются без сторонних сервисов.

## Управление

Выбрать цветок и стекло, нажать «Дальше», выбрать любую клетку, дождаться закапывания и нажать «Готово». Второй игрок начинает с третьей клетки шестого ряда. Стрелки на экране или клавиатуре двигают кисточку. «Копать» или пробел раскапывает текущую клетку. Во время анимации движение и повторная раскопка заблокированы. Звук включается после первого действия; кнопка звука находится сверху справа.

## Размещение

Содержимое папки можно поместить в корень указанного GitHub-репозитория. Все пути относительные, сборка и сторонние библиотеки не нужны. Для Pages достаточно статического размещения ветки из корневой папки. Файл `.nojekyll` включён. Репозиторий: https://github.com/propodgotovkaa-creator/klad

Для Genially после публикации вставить публичную HTTPS-ссылку в iframe с размером 16:9. Само приложение пропорционально масштабируется под размеры iframe без прокрутки. Реальный Genially и физические планшеты ещё не проверены. На телефоне удобнее альбомная ориентация.

## Проверки

`node --test tests/gameState.test.js`: 6 тестов, включая все 36 координат, начальную позицию, границы, блокировки, повторную раскопку, попадание и сброс.
В браузере пройден цикл: выбор → закапывание → пустая ямка → движение вверх → находка → увеличение → новая игра. Растровые ресурсы загружаются локально.

## Файлы

- `src/gameState.js`: независимая координатная логика.
- `src/graphics.js`: рисунки, стекло, поле и ямки.
- `src/digging.js`: динамическая маска и частицы грунта.
- `src/audio.js`: тихие синтезированные эффекты без сетевых запросов.
- `src/main.js`: экраны, управление и анимационный цикл.
- `assets/`: отдельно созданные рисунки грунта, фона, цветов, стекла и кисточки.

Шрифт Qanelas не предоставлен; используется локальный Trebuchet MS с резервным sans-serif. Название Qanelas оставлено первым в CSS для устройств, где он установлен.

## Правила и звук

При каждом открытии страницы автоматически показываются правила. Два педагогических варианта: поиск по устным указаниям и «горячо — холодно», где ищущий проговаривает свои движения, а спрятавший устно оценивает приближение. Автоматической подсказки расстояния нет. Правила доступны повторно по кнопке «?». Оставлен только звук копания; выбор, движения, закапывание и находка без звука.
